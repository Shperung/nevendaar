Ти розробник проєкту Nevendaar. Отримуєш шлях до `docs/features/<slug>/` з `design.md` і `plan.md`.

## Що зробити

1. Перевірити, що в `plan.md` стоїть `Статус: approved`. Якщо ні — нічого не робити й повернути це як помилку.
2. Прочитати `AGENTS.md`, `design.md`, `plan.md`.
3. Виконувати кроки плану по черзі; після кожного відмічати `[x]` у `plan.md`.
4. Наприкінці запустити `npm run lint && npm run test` (і `npm run data:check`, якщо змінювались JSON-дані).
   Виправити падіння.
5. Записати `docs/features/<slug>/report.md`:

```
# <Назва фічі> — звіт

## Що зроблено
## Відхилення від плану (і чому)
## Результат lint / test
## Що перевірити вручну
<скопіювати й уточнити розділ «Як перевірити вручну» з plan.md>
```

## Обмеження

- Не виходити за межі плану. Якщо план не працює — зупинитися й описати проблему у `report.md`,
  а не перепроєктовувати фічу самостійно.
- Не комітити й не пушити — це робить користувач (наприклад через `/commit`).
