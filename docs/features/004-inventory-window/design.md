# Вікно інвентаря — геймдизайн

## Ідея

Вікно інвентаря героя: функціонально як у Diablo, візуально як `reference.jpg` (камінь, пергамент, ромбічні
слоти навколо фігури героя, рюкзак унизу). Модальне вікно на HTML/CSS через `<dialog>`, відкривається
медальйоном «Інвентар» у HUD і клавішею `I`. У цьому кроці — лише каркас: порожні слоти екіпіровки, порожній
рюкзак, панель героя зі статами. Предмети, перетягування й лут — наступна фіча, але розкладка вже під них.

**Оригінальність (`AGENTS.md` §1).** Від референсу беремо лише композицію (пергамент зліва, кам'яна рама з
фігурою по центру, ромбічні слоти, стрічка рюкзака знизу), матеріали й настрій. Не копіюємо фігуру,
орнаменти, іконки, знамена, кількість і порядок слотів референсу. Кожен ассет генерується з нуля.

**Відхилення від стеку.** `AGENTS.md` §2 зараз забороняє DOM-базований ігровий UI («Контейнери PixiJS …
Без React/DOM»). Користувач свідомо обрав DOM (`<dialog>` + CSS) для вікон. Разом із фічею треба оновити
`AGENTS.md`: §2 (рядок UI і список заборон — дозволити нативні HTML/CSS-вікна без фреймворків, HUD лишається
на Pixi), §3 (`ui/` — де лежать DOM-вікна й стилі), §4 «UI-арт» (CSS-ассети вікон).

## Як це в серії Diablo

- **D1:** вікно інвентаря займає праву половину екрана, гра не зупиняється. Фігура-силует зі слотами:
  голова, амулет, тіло, дві руки, два кільця (7). Рюкзак — сітка 10×4, предмети мають розмір (1×1 … 2×3),
  тобто «тетріс». Золото лежить купками в клітинках. Відкриття `I`, закриття `I` або кнопкою.
- **D2:** те саме розташування праворуч, лист персонажа (`C`) — окремо ліворуч; обидва можна тримати
  відкритими, тоді від світу лишається смужка посередині. 10 слотів: голова, амулет, тіло, права й ліва рука
  (зі свапом `W`), рукавиці, пояс, чоботи, 2 кільця. Рюкзак 10×4 з «тетрісом». Золото — окремий рядок.
  `Esc` закриває всі вікна, а не відкриває меню. Пауза лише в меню `Esc` у синглі; інвентар паузу не ставить.
  Гравці люблять «тетріс» як ностальгію, але лають за вічне перекладання й тісноту.
- **D3:** одна панель праворуч: зверху paper doll із 13 слотами (додались плечі, наручі, штани), знизу
  рюкзак 10×6, предмети 1×1 або 1×2. Порожній слот показує тьмяний силует типу предмета. Гра не на паузі.
- **D4:** панель праворуч, рюкзак 11×3 з вкладками за типом (екіпіровка, розхідники, квестове), усі предмети
  1×1. Порожні слоти з силуетами, тултіп «порівняння» при наведенні. Пауз немає (онлайн). Хвалять за
  швидкість і простоту, лають за малий рюкзак.
- **Immortal:** мобільний UI — повноекранне меню, гра йде на фоні. Слоти екіпіровки фіксовані, рюкзак —
  список/сітка 1×1 без обмежень на форму. Для нас нецікаво.
- **Висновки:**
  - Беремо: paper doll у центрі зі слотами навколо (D1/D2); 10 слотів D2 — повний набір без надлишку D3;
    відкриття/закриття тією ж клавішею, `Esc` закриває вікно, а не відкриває меню (D2); тьмяний силует у
    порожньому слоті та тултіп із назвою слота (D3/D4); золото рядком у вікні (D2).
  - Рюкзак: сітка з клітинками 1×1 (D3/D4) — простіше для лута й drag&drop наступної фічі, без «тетрісу».
    Розмір 10×4 (40 клітинок, як D1/D2 за площею), уся сітка видна одразу. Стрічку зі стрілками, як у
    референсі, відкинуто — повільніше шукати предмети.
  - Відкидаємо: два вікна одночасно ліворуч/праворуч (у нас одне модальне); свап зброї; вкладки D4;
    лист персонажа окремим вікном — у нас панель героя вбудована у вікно, як у референсі.
  - Пауза: як у Diablo — інвентар паузу не ставить, світ живе далі. Вікно модальне лише щодо керування:
    нові накази герою (кліки по світу, хоткеї) не приймаються.

## Як це працює в Nevendaar

**Стани.** `закрито` ⇄ `відкрито`. Одночасно відкрите максимум одне модальне вікно.

| Дія                                    | Результат                                                            |
| -------------------------------------- | -------------------------------------------------------------------- |
| `I` або клік по медальйону «Інвентар»  | закрито → відкрито                                                   |
| `I` у відкритому вікні                 | відкрито → закрито                                                   |
| `Esc`                                  | закриває вікно; меню `Esc` у цьому ж натисканні **не** відкривається |
| кнопка «×» у кутку рами                | закриває                                                             |
| клік поза рамою (по затемненню)        | нічого — щоб випадковий клік не закривав вікно й не пускав героя     |
| інші хоткеї (`1–4`, `F`, `ПКМ`, `Tab`) | ігноруються, поки вікно відкрите                                     |

**Без паузи.** Поки вікно відкрите, світ живе: монстри ходять і б'ють, анімації й респаун працюють, видно
під затемненням. Вікно блокує лише керування: кліки по світу не доходять, утримання ЛКМ скидається, інші
хоткеї ігноруються. Поточний наказ героя **не** скасовується: він дійде до точки, куди вже йшов, або завдасть
поточного удару й зупиниться (автоповтор атаки вимикається разом з утриманням ЛКМ). Відкривати інвентар у
бою — ризик гравця, як у Diablo. Клік, яким закрили вікно, не стає наказом руху.

**Медальйон у HUD.** «Інвентар» перестає бути заглушкою (`stub: false`). Поки вікно відкрите — медальйон у
стані `pressed` (натиснутий перемикач, як мініпанель D2). Тултіп: «Інвентар (I)».

**Розкладка вікна** (дизайн-розмір 960×640 px, масштаб `min(1, ширина·0.92/960, висота·0.92/640)`, по
центру екрана поверх і гри, і бічної панелі):

```
┌──────────────┬───────────────────────────────────────────┐
│ Ім'я героя   │  ◇Шолом                          ◇Амулет  │
├──────────────┤                                           │
│ Стати        │  ◇Зброя        [фігура героя]     ◇Лівиця │
│              │                                           │
├──────────────┤  ◇Рукавиці                         ◇Пояс  │
│ Золото       │                                           │
│ Глибина      │  ◇Кільце   ◇Обладунок  ◇Чоботи   ◇Кільце  │
├──────────────┴───────────────────────────────────────────┤
│ Рюкзак: сітка 10×4 клітинок 1×1                        × │
└──────────────────────────────────────────────────────────┘
```

- **Ліва колонка (пергамент)** — три таблички, як у референсі: ім'я; стати; золото й глибина.
- **Центр (кам'яна рама)** — фігура героя на темному тлі готичної зали, 10 ромбічних слотів навколо.
  Обладунок і чоботи внизу по центру, щоб не перекривати фігуру.
- **Низ** — рюкзак, 10 колонок × 4 рядки, квадратні клітинки в кам'яних рамках.

**Слоти екіпіровки** (id → назва → що прийматиме в наступній фічі):

| id        | Назва     | Приймає                  |
| --------- | --------- | ------------------------ |
| `head`    | Шолом     | шоломи, корони, каптури  |
| `amulet`  | Амулет    | амулети                  |
| `weapon`  | Зброя     | одноручна/дворучна зброя |
| `offhand` | Лівиця    | щит, другорядний предмет |
| `gloves`  | Рукавиці  | рукавиці                 |
| `belt`    | Пояс      | пояси                    |
| `ring1`   | Кільце    | кільця                   |
| `ring2`   | Кільце    | кільця                   |
| `body`    | Обладунок | нагрудники, мантії       |
| `boots`   | Чоботи    | чоботи                   |

Порожній слот: ромбічна рамка + тьмяний (≈25 % альфа) силует типу предмета. Наведення — рамка світлішає,
тултіп із назвою слота. Клік по порожньому слоту нічого не робить.

**Рюкзак.** 40 клітинок, адресація `(col, row)`, `0..9 × 0..3`, зліва направо, згори вниз. Наведення
підсвічує клітинку. Без тултіпа (порожня). Розмір рюкзака — з даних, розкладка підлаштовується.

**Панель героя** (лише читання, значення з ECS героя; світ живий, тож оновлюються щокадру, поки вікно
відкрите — здоров'я падає в бою, золото росте при підборі):

| Рядок           | Джерело                       | Формат               |
| --------------- | ----------------------------- | -------------------- |
| Ім'я            | те саме, що в HUD («Вотан»)   | заголовок            |
| Здоров'я        | `Health.current / Health.max` | `87 / 120`           |
| Шкода           | `Attack.damage`               | ціле                 |
| Швидкість атаки | `1 / Attack.cooldown`         | `1.4 / с`            |
| Дальність атаки | `Attack.range`                | `1.5 тайла`          |
| Швидкість руху  | `Speed.value`                 | `4.0 тайла/с`        |
| Золото          | `Wallet.gold`                 | з розділювачем тисяч |
| Глибина         | поточна глибина з HUD         | ціле                 |

Рівня, досвіду й опорів поки немає — рядків під них не додаємо. Коли з'являться предмети, стати
показуватимуть результат `StatCalc.compute` (база + екіпіровка).

**Крайові випадки.**

- Герой мертвий / чекає респауну: `I` і медальйон не відкривають вікно. Якщо герой загинув із відкритим
  вікном — вікно лишається відкритим, стати показують стан після респауну.
- Вікно браузера змінює розмір при відкритому вікні — масштаб перераховується.
- Фокус: при відкритті фокус на кнопці «×»; `Tab` усередині вікна не виходить за його межі (нативна
  поведінка модального `<dialog>`).
- Втрата фокусу вкладки — вікно лишається відкритим.

## Дані

Склад слотів і розмір рюкзака — дані, розкладка (координати) — у коді/CSS, як у HUD.
`public/assets/data/inventory.json`:

```json
{
  "backpack": { "cols": 10, "rows": 4 },
  "slots": [
    { "id": "head", "title": "Шолом", "accepts": ["helm"] },
    { "id": "amulet", "title": "Амулет", "accepts": ["amulet"] },
    { "id": "weapon", "title": "Зброя", "accepts": ["weapon1h", "weapon2h"] },
    { "id": "offhand", "title": "Лівиця", "accepts": ["shield", "weapon1h"] },
    { "id": "gloves", "title": "Рукавиці", "accepts": ["gloves"] },
    { "id": "belt", "title": "Пояс", "accepts": ["belt"] },
    { "id": "ring1", "title": "Кільце", "accepts": ["ring"] },
    { "id": "ring2", "title": "Кільце", "accepts": ["ring"] },
    { "id": "body", "title": "Обладунок", "accepts": ["armor"] },
    { "id": "boots", "title": "Чоботи", "accepts": ["boots"] }
  ]
}
```

`accepts` у цьому кроці не використовується, але фіксує типи предметів для наступної фічі.

## Що бачить гравець

- Натискає `I` або медальйон — екран затемнюється (≈60 % чорного з легким віньєтуванням), вікно з'являється
  з коротким fade + scale 0.97→1 (~120 мс). Закриття — зворотна анімація. Гра під вікном триває.
- Вікно: важка кам'яна рама з бронзовими накладками й самоцвітами-заклепками в кутах; ліворуч пергаментні
  таблички з темно-коричневим текстом (засічковий шрифт, як у HUD); у центрі темна готична зала з фігурою
  героя в тумані; ромбічні слоти з тьмяними силуетами; унизу сітка рюкзака.
- Наведення на слот/клітинку — тепле золоте світіння рамки; на слот — тултіп у стилі HUD.
- Кнопка «×» — маленький кам'яний медальйон у правому верхньому куті рами (стани як у HUD-медальйонів).
- Фігура героя в залі — окремий намальований арт (`inv_doll`), як у референсі; кадр спрайта не
  використовується. Placeholder-рівень допустимий для решти: рама — CSS-градієнти й `border` у тонах каменю,
  пергамент — плаский бежевий фон, рамки клітинок — CSS.

## Візуал і ассети

**Арт-дирекшен.** Похмурий інтер'єр: сіро-коричневий тесаний камінь з тріщинами, потемніла бронза, старий
пергамент із плямами, тьмяне тепле світло згори ліворуч (одне джерело для всіх деталей). Насичені акценти —
лише самоцвіти-заклепки (холодне бурштинове/кров'яне сяйво). Ромбічні рамки слотів — кутаста готика з
різьбленням, без конкретних гербів. Фігура героя — оригінальна, у потертих обладунках, стоїть фронтально,
руки трохи розведені, щоб навколо читалися слоти. Ассети в 2× дизайн-px (як `public/assets/ui/`), сирі
генерації — `art/concepts/ui/` на magenta-фоні (для об'єктів із вирізанням), тайлові текстури — без фону.

| Ассет           | Розмір (2×)     | Примітка                                                                                          |
| --------------- | --------------- | ------------------------------------------------------------------------------------------------- |
| `inv_frame`     | 1920×1280       | рама вікна з прозорими вікнами під колонку, центр і рюкзак; або 9-slice                           |
| `inv_stone`     | 512×512 тайл    | безшовне тло каменю (можна перевикористати `panel_stone`)                                         |

## Поза скоупом

- Предмети, іконки предметів, drag&drop, порівняння, тултіпи предметів, екіпірування → зміна статів
  (`StatCalc`) — наступна фіча.
- Генерація луту, підбір предметів у рюкзак, золото як предмет.
- Свап зброї, вкладки рюкзака, сортування, сховище/скриня, торговці.
- Лист персонажа `C`, навички `S`, журнал `Q` (лишаються заглушками), меню `Esc`.
- Список навичок у лівій колонці (як у референсі) — немає системи навичок.
- Збереження вмісту інвентаря — пункт 6 віхи.
- Звуки відкриття/закриття.

## Ухвалені рішення

1. **Пауза — ні.** Світ живе, як у Diablo; вікно блокує лише керування героєм, поточний наказ героя
   доводиться до кінця, стати у вікні оновлюються наживо.
2. **Рюкзак** — повна сітка 10×4 без прокрутки.
3. **Фігура героя** — як у референсі: окремий намальований оригінальний арт героя на повний зріст у готичній
   залі (`inv_doll`), не кадр спрайта. При зміні екіпіровки фігура не змінюється.
4. **Медальйон «Персонаж» (`C`)** — лишається заглушкою; лист персонажа буде окремим вікном пізніше.
