- `src/ui/PanelLayout.ts` (без Pixi): таблиця блоків (`crown 80`, `minimap 160`, `row 64`, `column` тягнеться,

  `panelLayout`, `clampTooltip`, `healthFraction`. Спека `tests/ui/PanelLayout.test.ts`.
- `src/ui/Hud.ts` переписано: процедурна панель на всю висоту (камінь, фаски, залізні пояси із заклепками
  й ромбиками, тягнуча колона-вставка з ребрами), корона з 3 медальйонами, рамка мінікарти + Tab, ряд із
  4 медальйонів, портрет героя (`hero_idle_4_00`) під маскою, пергамент (ім'я, здоров'я, монета + золото),
  лічильник глибини `1`, кільце з 6 слотів і самоцвіт здоров'я з тултіпом, фініал. Поглинає `pointerdown`.
  `toggleFullscreen()` + синхронізація іконки/тултіпа за `fullscreenchange`.

  цифра-бейдж для пояса.
- `src/ui/Tooltip.ts`: спільний тултіп ліворуч від панелі, притиснутий до екрана.
- `src/ui/Minimap.ts`: місцевість запікається один раз у текстуру (`generateTexture`), зсувається
  лише коли герой рухається; ромбик героя в центрі. Крапки купок і монстрів прибрано заради продуктивності.
- `src/core/Camera.ts`: працює від `viewport()` (екран мінус панель).
- `src/core/Input.ts`: `overPanel`. `src/core/Game.ts`: створення панелі/мінікарти/тултіпа, `layout` на старті
  й `resize`, заморожування `pointerScreen` над панеллю, `F` → повний екран, `hud.update({ gold, hp, maxHp })`.
- `src/ecs/systems/render.ts`: підпис купки ховається при `Input.overPanel`.
- `src/ui/FullscreenButton.ts` видалено.

## Відхилення від плану (і чому)

- **Здоров'я в пергаменті — два рядки** (`Здоров'я` / `87 / 100`), а не один: у пергамент шириною 90 px
  рядок `Здоров'я 100 / 100` не влазить читабельним шрифтом.
- **`Medallion` — клас** (`new Medallion(options, tooltip)`) замість `createMedallion(...)`: йому потрібні методи
  `setIcon` / `setTitle` для кнопки повного екрана.
- **Ширина панелі — `hud.panelWidth`**, а не `hud.width`: `Container.width` у Pixi рахується з меж вмісту.
- **`Tooltip.edge`**: ліва межа панелі, яку виставляє `hud.layout`; медальйони й самоцвіт передають її в
  `show(lines, anchorX, anchorY)`, щоб тултіп висів ліворуч від панелі, а не від кнопки.
- Текстура мінікарти генерується з `resolution: 2`, щоб не розмивалась при масштабі панелі 1.4.
- **Мінікарта урізана** до місцевості й героя (без крапок купок і монстрів) на прохання користувача.
- **Продуктивність (поза планом)**: гра лагала через ~17.6k спрайтів перешкод у шарі (сортування + `CullerPlugin`
  щокадру). `CullerPlugin` прибрано; `drawMap` тримає в шарі лише чанки 16×16 тайлів під камерою, юніти й
  купки поза екраном ховаються й не оновлюються. Кадр ~8 мс при 120 Гц без просідань.
- Prettier переформатував `design.md` / `plan.md` (інакше `npm run lint` падав на них).

## Результат lint / test

- `npm run lint` — ок (ESLint + Prettier).
- `npm run test` — 8 файлів, 32 тести, усі пройшли (з них 7 нових у `tests/ui/PanelLayout.test.ts`).

  рендеряться, герой по центру ігрової зони.

## Що перевірити вручну

1. `npm run dev`: праворуч темна кам'яна колона на всю висоту; старого лічильника золота й кнопки
   повного екрана у верхніх кутах немає; герой по центру зони ліворуч від панелі.
2. Змінити висоту вікна: панель масштабується, тягнеться лише колона між рядом кнопок і портретом;
   дуже низьке вікно — низ обрізається, нічого не налазить одне на одне. Вузьке вікно — панель ≤ 40 % ширини.
   Текст на панелі при великому масштабі не розмитий.
3. Піти героєм до правого краю — камера зсувається раніше, ніж герой зайде під панель.
4. Клік і утримання на панелі — герой не рухається. Затиснути ЛКМ на сцені й завести курсор на
   панель — герой іде до точки біля межі; відпустити над панеллю — утримання знімається.
5. Курсор над купкою біля межі, потім на панель — підпис «N золота» зникає.
6. Навести на заглушку — золота рамка, тултіп «Інвентар (I)» / `Ще недоступно` ліворуч від панелі;
   затиснути — медальйон вдавлюється, нічого не відбувається. Тултіп біля верху/низу екрана не виходить
   за край. Курсор-кинджал над заглушками, `pointer` лише над кнопкою повного екрана.
7. Кнопка повного екрана й `F` — вхід/вихід, іконка (кути назовні / всередину) і тултіп міняються;
   вихід через Esc браузера теж синхронізує іконку.
8. Мінікарта: герой у центрі, місцевість зсувається при ході; купок і монстрів на ній немає.
9. Отримати удар — самоцвіт і рядок здоров'я в пергаменті зменшуються, тултіп самоцвіта показує
   `Здоров'я N / M`; підібрати золото — сума в пергаменті зростає; у портреті — герой.
10. Кільце: верхній слот (меч) — тултіп `Удар — ЛКМ` / `Ближня атака`, без підсвітки й натискання;
    слоти пояса з цифрами 1–4 — заглушки «Зілля (N)».
